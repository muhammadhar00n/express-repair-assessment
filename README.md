# Express Repair Assessment

ASP.NET Core MVC (.NET 6) implementation of all five screening tasks.

## Run

1. Install the .NET 6 SDK.
2. From this folder run `dotnet restore` and `dotnet run`.
3. Open the displayed HTTPS URL.
4. For the SignalR requirement, open `/Notifications` in two browser tabs.

Data is intentionally stored in memory and resets when the application restarts.
